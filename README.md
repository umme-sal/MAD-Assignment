# StudyFlow
Advanced student productivity web application for a Hybrid Mobile Application Development assignment.

Features:
- Dashboard
- Task manager with search/filter/sort
- Categories and priorities
- Due dates
- Study planner/calendar
- Focus/Pomodoro timer
- Productivity analytics
- Goals
- Dark mode
- LocalStorage persistence
- Responsive mobile UI

## Capacitor
Copy `index.html`, `style.css`, and `script.js` into your Capacitor web asset directory (usually `www/`), then run your normal Capacitor sync/open Android workflow.

Example:
npm install
npx cap sync android
npx cap open android
